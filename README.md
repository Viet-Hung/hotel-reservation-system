# Hotel Reservation System

Clean Architecture + DDD implementation in .NET 8 with Angular 20 frontend.

## Tech Stack

- Backend: .NET 8 Web API, EF Core 8, SQL Server
- Frontend: Angular 20, Material Design
- Patterns: Clean Architecture, CQRS, DDD
